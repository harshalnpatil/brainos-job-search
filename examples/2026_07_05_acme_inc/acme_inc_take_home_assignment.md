# Problem & users (steps 1–3)

## 1. Clarify the situation
> Agent note: Define the primary goal, revenue, profits, or user base. State the desired outcome from the analysis.

## 2. Identify the users
> Agent note: Define the end user and the buyer. Who is in the target market, and who uses similar products but is not?

## 3. Identify user needs
> Agent note: Capture the user's mindset, needs, and challenges. Use needs, jobs-to-be-done, or a customer journey map.

---

# Solution & execution (steps 4–6)

## 4. Identify gaps vs. existing products
> Agent note: Explain how users meet their needs today and where the gaps are. Prefer a steelman of alternatives over a strawman.

## 5. Identify feature improvements
> Agent note: Link gaps to at least three feasible improvements. If the product exists, connect features to customer needs.

## 6. Execution plan
> Agent note: Define MVP and MLP. For network-effect products, technical execution may overlap with go-to-market.

---

# GTM, metrics, risks (steps 7–9)

## 7. Go-to-market plan
> Agent note: Explain where customers look for solutions, how they will find this product, and what is required to be present there.

## 8. Metrics and counter-metrics
> Agent note: Explain how success will be measured. Define primary metrics and counter-metrics for unintended consequences.

## 9. Evaluate risks and trade-offs
> Agent note: Explain the trade-offs of choosing one feature or path over others. Call out key risks.
